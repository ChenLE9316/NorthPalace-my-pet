# Lenvu Reference Library

This directory contains **reference-only** character material. It is not the runtime sprite library.

The primary anatomy WebP preserves the original 1536×1024 canvas but is currently a transport-optimized derivative. The original source filename, dimensions and SHA-256 are preserved in `manifest.json` so provenance remains explicit.

Visual authority is defined by `docs/LENVU_VISUAL_GROUND_TRUTH.md`. Original image evidence outranks textual summaries, inferred normalization coordinates and generated review candidates.

Production animation must be derived from a canonical master with fixed anatomy, anchors, pivots and identity markings, but the canonical master itself must remain faithful to the original source sheets. If a master/candidate drifts into a different species silhouette, chibi proportions, altered fur palette or incorrect identity markings, it fails QA rather than becoming a new reference.
